## Featured projects

### [GestãoIP — Network Monitoring Platform](https://github.com/HenriqueC-r/GestaoIP)

Network monitoring software built for small and medium-sized businesses and used in real production environments.

`Python` `ICMP` `Telegram API` `SQLite` `Multi-client architecture`

- Monitors network devices through ICMP checks
- Sends real-time outage and recovery notifications through Telegram
- Stores events and supports separate client environments

### [Login System PHP — Authentication REST API](https://github.com/HenriqueC-r/Login-System-PHP)

Authentication backend built with native PHP and MySQL as part of a full-stack project with **[Mirianrl](https://github.com/Mirianrl)**, who developed the Vue.js and Quasar frontend.

`PHP` `MySQL` `JWT` `PDO` `Composer` `REST API`

- JWT-based authentication and protected routes
- Password hashing and PDO prepared statements
- Environment-based configuration with `.env`
- Integration with a separate Vue.js frontend

### [IARA — Intelligent Autonomous Remote Assistant](https://github.com/HenriqueC-r/IARA-Intelligent-Autonomous-Remote-Assistant)

`Python` `Artificial Intelligence` `Task Planning` `Automation`

`Business Software` `Database` `Production Deployment`
