### 👨‍💻 About Me

I'm a Software Engineering student focused on backend architecture with **PHP (Laravel)** and **Python**.

My work goes beyond coursework: I develop software used in real production environments for local businesses—ranging from network monitoring tools and desktop RPA automations to automotive marketplaces and authentication APIs. I enjoy working close to the infrastructure layer, handling database modeling, API security, Docker environments, and Linux servers.

- ⚙️ **Core Focus:** RESTful APIs, authentication flows, database design, and task automation.
- 🐳 **Environment:** Daily Linux user working with Docker, Nginx, Git, and relational databases.
- 🎯 **Currently:** Developing the **Tá na Garagem** automotive marketplace (Laravel 13 + Vue 3) and expanding commercial network monitoring solutions.
